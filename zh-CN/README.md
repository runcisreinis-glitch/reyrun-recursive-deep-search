# 什么是递归深度搜索？

你问 AI：“我想让它下次查资料比这次更靠谱，有什么办法？”它回答：“可以优化提示词，也可以增加记忆。”听起来有道理，可你还是不知道该试哪个办法，又怎么判断它有没有用。

Reinis Runcis 做了一个免费的搜索技能（skill）。用它查这个问题，AI 会去看已经有人写好的工具，查开发者遇到过哪些问题，再找个小任务来检验。例如，先保留原来的搜索方法，只改一条规则，再用双方都没见过的问题比较结果。[项目里有这次实际研究的例子（英文）](../examples/real-result.md)。

“递归”说的是：这一轮找到的线索，会成为下一轮要查的问题。比如开发者提到一个旧项目，AI 就顺着名字去找源码，看它究竟做到了哪一步。它还会找其他行业有没有用不同术语解决过类似问题，并核对哪些证据支持或推翻自己的判断。

**怎么用？** 把这页的网址和你想查的问题一起发给平时聊天的 AI。只做这一次搜索，用能联网查资料的聊天工具就行。这套技能从安装到使用都免费。

如果还想让 AI **下次接着改进**，它需要一个以后还能读写的文件夹，用来留下这次试过的办法和检验结果。你的聊天工具已经能访问这样的文件夹，就可以直接用；如果还没有，把[设备连接桥的中文说明](https://github.com/runcisreinis-glitch/REYRUN-Chatbot-Bridge/blob/main/README.zh-CN.md)也发给它。
